MiniRADS In progress

A small multi-tenant SaaS platform: one system that many businesses share, where each business can only ever see its own data.

  • API: ASP.NET Core, with three kinds of authentication
  • Database: Cosmos DB, partitioned so each business's data stays separate
  • Portal: Blazor web app, with end-to-end tests
  • Payments: Stripe, where only verified webhooks can activate an account
  • Hosting: Azure, with separate staging and production environments

Roadmap

  1. Foundations: dev setup and team Git workflow (done)
  2. Static hosting on Azure: this portfolio (in progress)
  3. API: register, log in, protected endpoints (next)
  4. Database: Cosmos DB with tenant isolation
  5. Portal: Blazor app with end-to-end tests
  6. Payments: Stripe Checkout and webhooks
  7. Operations: CI/CD pipeline, monitoring and alerts

How I work

  • Plan first: work is split into phases, each with a clear goal and a check at the end.
  • Every change reviewed: nothing goes in without a pull request.
  • Staging before production: changes land on a test environment first, and only reach the live one once they've been checked.
  • Written down: a learning log and project notes, so decisions are documented, not just remembered.
